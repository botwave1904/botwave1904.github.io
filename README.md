# BOTWAVE — Independent Games

Studio: https://botwave1904.github.io/

- [Nadie Mira Arriba — browser game, Android debug download, and controls](https://botwave1904.github.io/nadie-mira-arriba/)
- [Featured games / current lotee browser edition](https://botwave1904.github.io/#games)

The Godot 4.7.2 web build is single-threaded and does not require cross-origin-isolation headers. Browser play needs WebGL 2 and a keyboard or compatible gamepad; this build has no touch controls.

Android downloads are debug/sideload builds, not a Play Store or production release. Android may request permission to install unknown apps. APKs cannot be installed on iOS.
